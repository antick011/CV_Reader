# CV Reader

**CV Reader** is a Flask-based application that allows users to upload and analyze CVs (PDF and DOCX formats). It uses **Google Generative AI** to process the documents and provide insights into the CV content.

> **Note:** This project is **for educational purposes only**.  
> **Cloning, forking, or downloading this repository is strictly prohibited**. The code is not open source and cannot be reused without explicit permission.

## Features

- Upload and parse CVs (PDF and DOCX formats)
- Use **Generative AI** for analysis and insights
- Simple web interface built with Flask

## Technologies Used

- **Framework**: Flask
- **Libraries**:
  - **fitz (PyMuPDF)** for PDF parsing
  - **python-docx** for DOCX handling
  - **google.generativeai** for AI processing
- **Language**: Python
